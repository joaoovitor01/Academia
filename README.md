# 🏋️ Academia Peso pesado — Sistema & Portal Web para Academias

O Peso pesado é um sistema web completo desenvolvido para gestão e experiência de membros em academias. A aplicação combina uma interface moderna para apresentação da academia e seus profissionais, um portal exclusivo para alunos acompanharem seus treinos e um painel administrativo robusto para controle financeiro e operacional.

---

## 📌 Funcionalidades Principais

### 🌐 Portal Público
* **Página Inicial (Menu):** Apresentação institucional da academia, estrutura física e perfil dos personal trainers disponíveis.
* **Planos:** Exibição detalhada de 3 modalidades de planos (Basic, Smart e VIP) para conversão de novos alunos.

### 🔐 Sistema de Autenticação Dupla
O projeto conta com dois fluxos de login distintos para atender às diferentes necessidades de acesso:

#### 1. Portal do Aluno (`Login Tipo 1`)
* **Perfil do Aluno:** Visualização de dados pessoais, status da matrícula e frequência.
* **Ficha de Treino:** Acesso rápido aos exercícios diários, séries, repetições e orientações dos personais.

#### 2. Painel Administrativo (`Login Tipo 2` - Gerência & Recepção)
* **Gestão Financeira:** Visualização do faturamento, fluxo de caixa e movimentações financeiras da empresa.
* **Controle de Estoque:** Gerenciamento de produtos, suplementos e itens vendidos na recepção.
* **Gestão de Alunos:** Consulta, cadastro e controle de todos os alunos matriculados no sistema.
